# Palindrome Rearranging

![Difficulty](https://img.shields.io/badge/difficulty-warm--up-green)
**Source:** CodeSignal

## 1. Problem

Given a string, determine whether its characters can be rearranged to form a palindrome (at most one character may have an odd frequency).

## 2. Solutions

| File      | Approach                                            | Time | Space |
| --------- | --------------------------------------------------- | ---- | ----- |
| Solution1 | HashMap frequency count, check odd-count characters | O(n) | O(k)  |
| Solution2 | Fixed-size frequency array, check odd counts        | O(n) | O(1)  |
