# Absolute Values Sum Minimization

![Difficulty](https://img.shields.io/badge/difficulty-warm--up-green)
**Source:** CodeSignal

## 1. Problem

Given a sorted array of integers, find the element that minimizes the total sum of absolute differences between itself and every other element in the array (i.e., return the median).

## 2. Solutions

| File | Approach | Time | Space |
|---|---|---|---|
| solution-1.java | Direct median index (ceiling) | O(1) | O(1) |
| solution-2.java | Direct median index (floor of midpoint) | O(1) | O(1) |
