# Century From Year

![Difficulty](https://img.shields.io/badge/difficulty-warm--up-green)
**Source:** CodeSignal

## 1. Problem

Given a year, return which century it falls in (e.g., year 1 through 100 is the 1st century, 101 through 200 is the 2nd, etc.).

## 2. Solutions

| File | Approach | Time | Space |
|---|---|---|---|
| solution-1.java | Integer division with remainder bump | O(1) | O(1) |
| solution-2.java | Direct arithmetic via (year - 1) / 100 + 1 | O(1) | O(1) |
