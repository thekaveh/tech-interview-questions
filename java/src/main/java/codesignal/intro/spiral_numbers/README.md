# Spiral Numbers

![Difficulty](https://img.shields.io/badge/difficulty-warm--up-green)
**Source:** CodeSignal

## 1. Problem

Fill an N x N matrix with the numbers 1 through N² in clockwise spiral order starting from the top-left corner.

## 2. Solutions

| File      | Approach                                                  | Time  | Space |
| --------- | --------------------------------------------------------- | ----- | ----- |
| Solution1 | Boundary-shrinking spiral fill (top, right, bottom, left) | O(N²) | O(N²) |
