# Alphabetic Shift

![Difficulty](https://img.shields.io/badge/difficulty-warm--up-green)
**Source:** CodeSignal

## 1. Problem

Given a lowercase string, shift each letter one position forward in the alphabet, wrapping 'z' back to 'a'.

## 2. Solutions

| File | Approach | Time | Space |
|---|---|---|---|
| solution-1.java | Single pass with modular arithmetic | O(n) | O(n) |
| solution-2.java | Stream chars with map | O(n) | O(n) |
