# Array Replace

![Difficulty](https://img.shields.io/badge/difficulty-warm--up-green)
**Source:** CodeSignal

## 1. Problem

Given an array of integers and two values, replace every occurrence of the first value with the second and return the modified array.

## 2. Solutions

| File      | Approach                         | Time | Space |
| --------- | -------------------------------- | ---- | ----- |
| Solution1 | Single pass in-place replacement | O(n) | O(1)  |
| Solution2 | Stream map with ternary          | O(n) | O(n)  |
