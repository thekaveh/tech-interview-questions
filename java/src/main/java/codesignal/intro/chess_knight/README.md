# Chess Knight

![Difficulty](https://img.shields.io/badge/difficulty-warm--up-green)

## 1. Problem

Given a knight's position on a chessboard, count how many of its up-to-eight possible L-shaped moves land on a valid square.

## 2. Solutions

| File | Approach | Time | Space |
|---|---|---|---|
| solution-1.java | Enumerate all 8 candidate moves, count in-bounds | O(1) | O(1) |
