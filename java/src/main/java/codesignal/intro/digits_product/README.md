# Digits Product

![Difficulty](https://img.shields.io/badge/difficulty-warm--up-green)
**Source:** CodeSignal

## 1. Problem

Given an integer product, find the smallest positive integer whose digits multiply to that product, or return -1 if no such integer exists.

## 2. Solutions

| File | Approach | Time | Space |
|---|---|---|---|
| Solution1 | Linear scan checking digit product of each candidate | O(n * d) | O(1) |
