# Circle Of Numbers

![Difficulty](https://img.shields.io/badge/difficulty-warm--up-green)

## 1. Problem

Given n numbers arranged in a circle, find the number that sits exactly opposite to a given starting position (i.e., n/2 positions away).

## 2. Solutions

| File | Approach | Time | Space |
|---|---|---|---|
| Solution1 | Direct arithmetic modulo n | O(1) | O(1) |
