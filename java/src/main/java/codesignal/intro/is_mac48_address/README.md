# Is Mac48 Address

![Difficulty](https://img.shields.io/badge/difficulty-warm--up-green)
**Source:** CodeSignal

## 1. Problem

Given a string, determine whether it is a valid MAC-48 address (six groups of exactly two uppercase hexadecimal digits separated by hyphens).

## 2. Solutions

| File | Approach | Time | Space |
|---|---|---|---|
| Solution1 | Split on hyphen, validate each group by length and hex parsing | O(1) | O(1) |
| Solution2 | Single regex match | O(1) | O(1) |
