# Are Equally Strong

![Difficulty](https://img.shields.io/badge/difficulty-warm--up-green)
**Source:** CodeSignal

## 1. Problem

Given the left- and right-hand strengths of two people, determine whether they are equally strong (same total strength and the same individual hand strengths in either order).

## 2. Solutions

| File      | Approach                               | Time | Space |
| --------- | -------------------------------------- | ---- | ----- |
| Solution1 | Sum check plus at least one hand match | O(1) | O(1)  |
| Solution2 | Direct two-way equality check          | O(1) | O(1)  |
