# Variable Name

![Difficulty](https://img.shields.io/badge/difficulty-warm--up-green)
**Source:** CodeSignal

## 1. Problem

Given a string, determine whether it is a valid programming variable name (starts with a letter or underscore, followed by letters, digits, or underscores only).

## 2. Solutions

| File | Approach | Time | Space |
|---|---|---|---|
| solution-1.java | Character-by-character validation with position check | O(n) | O(1) |
| solution-2.java | Single regex match | O(n) | O(1) |
