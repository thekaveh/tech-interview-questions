![Difficulty](https://img.shields.io/badge/difficulty-warm--up-green)
**Source:** CodeSignal

## 1. Problem

Given two items each with a value and weight, and a maximum carrying capacity, determine the maximum value you can carry (taking at most one or both items if they fit).

## 2. Solutions

| File      | Approach                                                          | Time | Space |
| --------- | ----------------------------------------------------------------- | ---- | ----- |
| Solution1 | Greedy: take higher-value item first, add second if weight allows | O(1) | O(1)  |
