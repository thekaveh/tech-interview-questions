# Knapsack Light

![Difficulty](https://img.shields.io/badge/difficulty-easy-yellowgreen)
**Source:** CodeSignal

## 1. Problem

You have a knapsack with a weight limit and two items, each with a value and a weight. Greedily pick the most valuable item that fits, then try to add the other if weight allows. Return the maximum total value you can carry.

## 2. Solutions

| File | Approach | Time | Space |
|---|---|---|---|
| Solution1 | Greedy: take the higher-value item first if it fits, then attempt the second | O(1) | O(1) |
