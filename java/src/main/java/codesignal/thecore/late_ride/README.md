# Late Ride

![Difficulty](https://img.shields.io/badge/difficulty-easy-yellowgreen)
**Source:** CodeSignal

## 1. Problem

You took a ride of n minutes after midnight. Convert n to hours and minutes, then return the sum of all digits in both the hour and minute values of that time.

## 2. Solutions

| File      | Approach                                                                | Time | Space |
| --------- | ----------------------------------------------------------------------- | ---- | ----- |
| Solution1 | Compute hours and minutes, then sum digits of each via a while loop     | O(1) | O(1)  |
| Solution2 | Decompose hours and minutes to individual digit places and sum directly | O(1) | O(1)  |
