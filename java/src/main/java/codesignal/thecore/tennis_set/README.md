![Difficulty](https://img.shields.io/badge/difficulty-easy-yellowgreen)

## 1. Problem

Given two players' game scores in a tennis set, determine whether the score reflects a valid completed set. A set ends at 6–x (x < 5), 7–5, or 7–6.
