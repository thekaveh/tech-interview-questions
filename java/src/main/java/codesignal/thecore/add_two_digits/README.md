# Add Two Digits

![Difficulty](https://img.shields.io/badge/difficulty-easy-yellowgreen)
**Source:** CodeSignal

## 1. Problem

Given a two-digit integer n (10 ≤ n ≤ 99), return the sum of its two digits. For example, the sum for 29 is 11 and for 48 is 12.

## 2. Solutions

| File | Approach | Time | Space |
|---|---|---|---|
| Solution1 | Iterative digit extraction via modulo loop | O(1) | O(1) |
| Solution2 | Direct arithmetic: tens digit plus units digit | O(1) | O(1) |
