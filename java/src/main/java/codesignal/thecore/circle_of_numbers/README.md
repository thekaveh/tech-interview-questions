# Circle Of Numbers

![Difficulty](https://img.shields.io/badge/difficulty-easy-yellowgreen)
**Source:** CodeSignal

## 1. Problem

Numbers 0 through n-1 are placed at equal intervals around a circle. Given n (even) and a starting position firstNumber, return the number directly opposite to it — i.e., the one exactly n/2 steps away.

## 2. Solutions

| File | Approach | Time | Space |
|---|---|---|---|
| Solution1 | Modular arithmetic: (firstNumber + n/2) mod n | O(1) | O(1) |
