# Is Power

![Difficulty](https://img.shields.io/badge/difficulty-easy-yellowgreen)
**Source:** CodeSignal

## 1. Problem

Given a positive integer n, determine whether it can be expressed as a^b for integers a ≥ 2 and b ≥ 2. The number 1 is considered a power (1^anything = 1).

## 2. Solutions

| File | Approach | Time | Space |
|---|---|---|---|
| Solution1 | Brute-force search over all bases 2–20 and valid exponents | O(log²n) | O(1) |
