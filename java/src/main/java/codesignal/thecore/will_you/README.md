![Difficulty](https://img.shields.io/badge/difficulty-easy-yellowgreen)
**Source:** CodeSignal

## 1. Problem

Determine whether a person will accept a marriage proposal based on three boolean attributes: whether they are young, beautiful, and loved. They accept if they are both young and beautiful but not loved, or if they are loved but lack at least one of youth or beauty.

## 2. Solutions

| File | Approach | Time | Space |
