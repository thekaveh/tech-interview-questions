# Stable Internship

![Difficulty](https://img.shields.io/badge/difficulty-medium-yellow)
**Source:** AlgoExpert

## 1. Problem

Given a list of interns and a list of teams, each with ranked preferences for the other, find a stable matching — a set of intern–team pairs such that no unmatched intern and team would both prefer each other over their current assignments. This is the classic Gale-Shapley stable matching problem.
