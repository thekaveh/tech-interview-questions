# One Edit

![Difficulty](https://img.shields.io/badge/difficulty-medium-yellow)
**Source:** AlgoExpert

## 1. Problem

Given two strings, determine whether they are at most one edit apart. A single edit is one insertion, one deletion, or one substitution of a character. Strings of identical content are zero edits apart (valid), and strings differing in length by more than one are never one edit apart.
