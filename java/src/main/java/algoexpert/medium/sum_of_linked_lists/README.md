# Sum Of Linked Lists

![Difficulty](https://img.shields.io/badge/difficulty-medium-yellow)
**Source:** AlgoExpert

## 1. Problem

Given two singly linked lists where each node represents one digit of a non-negative integer in reverse order (least significant digit first), return a new linked list in the same format representing their sum, including any carry.

## 2. Solutions

| File      | Approach                                      | Time         | Space        |
| --------- | --------------------------------------------- | ------------ | ------------ |
| Solution1 | Simultaneous traversal with carry propagation | O(max(m, n)) | O(max(m, n)) |
