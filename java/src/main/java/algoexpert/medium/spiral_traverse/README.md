# Spiral Traverse

![Difficulty](https://img.shields.io/badge/difficulty-medium-yellow)
**Source:** AlgoExpert

## 1. Problem

Given a 2-D matrix of integers, return all elements in spiral order — starting from the top-left, going right across the first row, then down the right column, then left across the bottom row, then up the left column, then repeating inward.

## 2. Solutions

| File | Approach | Time | Space |
|---|---|---|---|
| Solution1 | Iterative shrinking boundary with four-edge traversal | O(r·c) | O(r·c) |
| Solution2 | Recursive shrinking boundary | O(r·c) | O(r·c) |
