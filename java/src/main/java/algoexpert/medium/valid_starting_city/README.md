# Valid Starting City

![Difficulty](https://img.shields.io/badge/difficulty-medium-yellow)
**Source:** AlgoExpert

## 1. Problem

Given arrays of city-to-city distances and fuel amounts at each city, and a fuel efficiency value (miles per gallon), find the index of the one valid starting city from which a car can complete a full circular trip visiting every city in order without running out of fuel.
