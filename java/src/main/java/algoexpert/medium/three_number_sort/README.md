# Three Number Sort

![Difficulty](https://img.shields.io/badge/difficulty-medium-yellow)
**Source:** AlgoExpert

## 1. Problem

Given an array of integers containing only three distinct values (specified by an ordering array), rearrange the elements in place so they appear in the order given by the ordering array. This is the Dutch National Flag problem generalized to arbitrary values.
