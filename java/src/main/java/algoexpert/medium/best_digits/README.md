# Best Digits

![Difficulty](https://img.shields.io/badge/difficulty-medium-yellow)
**Source:** AlgoExpert

## 1. Problem

Given a string representing a large non-negative integer and an integer `numDigits`, remove exactly `numDigits` digits from the number to produce the largest possible remaining number. The relative order of remaining digits is preserved.
