# Bubble Sort

![Difficulty](https://img.shields.io/badge/difficulty-warm--up-green)
**Source:** AlgoExpert

## 1. Problem

Sort an integer array in ascending order in-place using the bubble sort algorithm and return it. Repeated passes bubble the largest unsorted element toward the end; an early-exit flag stops the algorithm as soon as no swap occurs in a pass. The array may contain duplicate or negative values.
