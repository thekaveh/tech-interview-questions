# Middle Node

![Difficulty](https://img.shields.io/badge/difficulty-warm--up-green)
**Source:** AlgoExpert

## 1. Problem

A singly linked list is provided; return the node at the middle of the list. When the list has an even number of nodes, the second of the two middle nodes is returned. The list is guaranteed to have at least one node.

## 2. Solutions

| File      | Approach                          | Time | Space |
| --------- | --------------------------------- | ---- | ----- |
| Solution1 | Count length, advance to midpoint | O(n) | O(1)  |
| Solution2 | Slow and fast pointer             | O(n) | O(1)  |
