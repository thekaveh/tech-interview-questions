# Binary Search

![Difficulty](https://img.shields.io/badge/difficulty-warm--up-green)
**Source:** AlgoExpert

## 1. Problem

A sorted array of distinct integers and a target value are provided; return the index of the target in the array, or -1 if it is absent. The array is guaranteed to be sorted in ascending order, so a logarithmic-time approach is possible. Negative integers may appear among the elements.

## 2. Solutions

| File | Approach | Time | Space |
|---|---|---|---|
| Solution1 | Iterative binary search | O(log n) | O(1) |
| Solution2 | Iterative, compareTo-based | O(log n) | O(1) |
| Solution3 | Recursive binary search | O(log n) | O(log n) |
