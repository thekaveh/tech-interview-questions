# Selection Sort

![Difficulty](https://img.shields.io/badge/difficulty-warm--up-green)
**Source:** AlgoExpert

## 1. Problem

Sort an integer array in ascending order in-place using selection sort and return it. Each pass selects the minimum element from the unsorted suffix and swaps it into its correct position at the front of that suffix. The array may contain duplicate or negative values.

## 2. Solutions

| File | Approach | Time | Space |
|---|---|---|---|
| Solution1 | Selection sort, min scan + swap | O(n²) | O(1) |
