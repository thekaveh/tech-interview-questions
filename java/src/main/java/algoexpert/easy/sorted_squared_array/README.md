# Sorted Squared Array

![Difficulty](https://img.shields.io/badge/difficulty-warm--up-green)
**Source:** AlgoExpert

## 1. Problem

A sorted array of integers (which may include negative values) is provided; return a new array of the squares of each element, also sorted in ascending order. Because negative numbers can produce large squares, the largest squares may come from either end of the input. The output array must be the same length as the input.

## 2. Solutions

| File | Approach | Time | Space |
|---|---|---|---|
| Solution1 | Two-pointer, fill output right to left | O(n) | O(n) |
| Solution2 | Two-pointer, compact loop header | O(n) | O(n) |
| Solution3 | Two-pointer, for-loop k decrement | O(n) | O(n) |
