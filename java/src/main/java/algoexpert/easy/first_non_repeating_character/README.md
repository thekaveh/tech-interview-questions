# First Non Repeating Character

![Difficulty](https://img.shields.io/badge/difficulty-warm--up-green)
**Source:** AlgoExpert

## 1. Problem

A string of lowercase letters is provided; return the index of the first character that does not appear more than once in the string, or -1 if every character is repeated. The leftmost qualifying character's index is the answer. The input string may be empty, in which case -1 is returned.

## 2. Solutions

| File      | Approach                   | Time | Space |
| --------- | -------------------------- | ---- | ----- |
| Solution1 | Frequency map, linear scan | O(n) | O(1)  |
