# Merge Sort

![Difficulty](https://img.shields.io/badge/difficulty-very--hard-red)
**Source:** AlgoExpert

## 1. Problem

Sort an array of integers using the merge sort algorithm. The implementation must be in-place (using an auxiliary array for merging rather than allocating new arrays at each recursive call) to achieve optimal space usage.

## 2. Solutions

| File      | Approach                                         | Time       | Space |
| --------- | ------------------------------------------------ | ---------- | ----- |
| Solution1 | Recursive merge sort with single auxiliary array | O(n log n) | O(n)  |
