# Find Loop

![Difficulty](https://img.shields.io/badge/difficulty-hard-orange)
**Source:** AlgoExpert

## 1. Problem

Given the head of a singly linked list that is guaranteed to contain a cycle, find and return the node where the cycle begins (i.e., the first node that is visited twice when traversing from the head).

## 2. Solutions

| File | Approach | Time | Space |
|---|---|---|---|
| Solution1 | Floyd's cycle detection (two-pointer) | O(n) | O(1) |
| Solution2 | Floyd's cycle detection (compact for-loop form) | O(n) | O(1) |
