# Max Sum Increasing Subsequence

![Difficulty](https://img.shields.io/badge/difficulty-hard-orange)
**Source:** AlgoExpert

## 1. Problem

Given an array of integers, find the increasing subsequence (elements in order, each strictly greater than the previous) whose sum is the largest. Return the maximum sum and the subsequence itself.

## 2. Solutions

| File | Approach | Time | Space |
|---|---|---|---|
| Solution1 | DP (LIS-style sums) with predecessor backtracking | O(n²) | O(n) |
