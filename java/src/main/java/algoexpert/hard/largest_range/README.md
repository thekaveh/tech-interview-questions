# Largest Range

![Difficulty](https://img.shields.io/badge/difficulty-hard-orange)
**Source:** AlgoExpert

## 1. Problem

Given an array of integers, find the longest sequence of consecutive integers (not necessarily in the array in order) that are all present in the array. Return the start and end of that range as a pair.

## 2. Solutions

| File | Approach | Time | Space |
|---|---|---|---|
| Solution1 | Hash set + BFS expansion from unvisited elements | O(n) | O(n) |
