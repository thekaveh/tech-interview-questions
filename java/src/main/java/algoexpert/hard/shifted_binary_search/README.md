![Difficulty](https://img.shields.io/badge/difficulty-hard-orange)
**Source:** AlgoExpert

## 1. Problem

Given a sorted array of distinct integers that has been rotated at an unknown pivot point, search for a target value and return its index. If the target is absent, return -1. The algorithm must run in O(log n).
