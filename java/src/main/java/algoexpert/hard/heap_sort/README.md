# Heap Sort

![Difficulty](https://img.shields.io/badge/difficulty-hard-orange)
**Source:** AlgoExpert

## 1. Problem

Sort an array of integers in ascending order in-place using the heap sort algorithm. Build a max-heap from the input, then repeatedly extract the maximum element to produce a sorted result.

## 2. Solutions

| File | Approach | Time | Space |
|---|---|---|---|
| Solution1 | In-place max-heap with sink (while-loop) | O(n log n) | O(1) |
| Solution2 | In-place max-heap with sink (for-loop, OOO child helper) | O(n log n) | O(1) |
