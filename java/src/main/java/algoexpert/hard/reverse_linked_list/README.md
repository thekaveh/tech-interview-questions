# Reverse Linked List

![Difficulty](https://img.shields.io/badge/difficulty-hard-orange)
**Source:** AlgoExpert

## 1. Problem

Given the head of a singly linked list, reverse it in-place and return the new head. No extra list or array may be allocated; only pointer reassignments are allowed.

## 2. Solutions

| File      | Approach                         | Time | Space |
| --------- | -------------------------------- | ---- | ----- |
| Solution1 | Iterative three-pointer reversal | O(n) | O(1)  |
| Solution2 | Recursive reversal               | O(n) | O(n)  |
