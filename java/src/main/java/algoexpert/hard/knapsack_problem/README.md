# Knapsack Problem

![Difficulty](https://img.shields.io/badge/difficulty-hard-orange)
**Source:** AlgoExpert

## 1. Problem

Given a list of items each with a value and a weight, and a knapsack with a maximum weight capacity, find the combination of items that maximizes total value without exceeding the capacity. Return the total value and the indices of the chosen items.

## 2. Solutions

| File      | Approach                                | Time   | Space  |
| --------- | --------------------------------------- | ------ | ------ |
| Solution1 | Bottom-up 2-D DP with item backtracking | O(n·c) | O(n·c) |
