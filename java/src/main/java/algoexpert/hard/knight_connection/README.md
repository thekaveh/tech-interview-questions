# Knight Connection

![Difficulty](https://img.shields.io/badge/difficulty-hard-orange)
**Source:** AlgoExpert

## 1. Problem

Given two squares A and B on an infinite chess board, find the minimum number of moves a knight needs to travel from A to B. A knight moves in an L-shape: two squares in one direction and one in the perpendicular direction.

## 2. Solutions

| --------- | ----------------- | ------------------------ | ----- |
