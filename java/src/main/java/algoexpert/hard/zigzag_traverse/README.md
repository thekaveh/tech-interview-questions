# Zigzag Traverse

![Difficulty](https://img.shields.io/badge/difficulty-hard-orange)
**Source:** AlgoExpert

## 1. Problem

Given a 2D matrix, return all its elements in zigzag (diagonal) order: traverse one diagonal from top-left to bottom-right, then the next diagonal in the opposite direction, alternating until all elements are visited.

## 2. Solutions

| File | Approach | Time | Space |
