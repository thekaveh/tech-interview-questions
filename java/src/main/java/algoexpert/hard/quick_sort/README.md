# Quick Sort

![Difficulty](https://img.shields.io/badge/difficulty-hard-orange)
**Source:** AlgoExpert

## 1. Problem

Sort an array of integers in ascending order in-place using the quicksort algorithm. Use a 3-way partitioning scheme so elements equal to the pivot are handled in a single pass.

## 2. Solutions

| File      | Approach                              | Time                        | Space        |
| --------- | ------------------------------------- | --------------------------- | ------------ |
| Solution1 | 3-way partition quicksort (recursive) | O(n log n) avg, O(n²) worst | O(log n) avg |
