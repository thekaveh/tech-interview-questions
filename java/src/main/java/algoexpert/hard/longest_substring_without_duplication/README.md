# Longest Substring Without Duplication

![Difficulty](https://img.shields.io/badge/difficulty-hard-orange)
**Source:** AlgoExpert

## 1. Problem

Given a string, find the longest substring that contains no repeated characters. Return the substring itself. If the entire string has unique characters, return it in full.

## 2. Solutions

| File | Approach | Time | Space |
|---|---|---|---|
| Solution1 | Sliding window with last-seen index map | O(n) | O(1) |
